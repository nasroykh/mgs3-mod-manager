# MGS3 Mod Manager v0.4.0-alpha.2 (prerelease)

**Alpha.** The Delta controls tester kit from v0.4.0-alpha.1, now with a small window app so it can be installed and removed without a terminal. The plugins are unchanged. The installer's default ("latest") stays on v0.3.0; this build is installed only on request.

## What is new

- **Window app, `mgs3mod-gui.exe`**, inside the kit. It is also published alone as `mgs3mod-gui_0.4.0-alpha.2_windows_amd64.zip`, the build input of the kit; that zip holds no packages and no `mgs3mod.exe`, so testers should download the kit. One window:
  - **Game folder**: found in your Steam libraries, or chosen with **Browse…**, and remembered in `%LOCALAPPDATA%\mgs3mod\gui.json` (WebView2 keeps its data in `%LOCALAPPDATA%\mgs3mod\webview`). It runs `doctor` and shows "Supported game version" or why not, with **Copy details** for reports.
  - **Delta controls**: **Install / Update** stores and turns on the ASI loader, `fpv-move` and `qcamo-face` from the kit folder (turning QCamo 1.0.4 off, and replacing an older plugin build), then verifies. **Uninstall** removes both plugins, turns QCamo back on if Install turned it off, and removes the ASI loader unless another enabled mod needs it.
  - **Play**: **Launch game** starts the game directly, skipping the Master Collection menus, through the manager's own launch checks (the same as `mgs3mod launch`). Launch profiles can be created, edited, renamed, deleted and made the default in the app: game region, language and button prompts, limited to the combinations the official launcher itself offers. Two combinations were played: North America, English, keyboard prompts, and Europe, French, Xbox prompts (French text and Xbox prompts in game); the others are marked "Not tested yet". Never tried on a Steam copy; the app says so there.
  - **Mods** (advanced): every stored mod with an on/off switch, **Add mod package…**, **Verify** and **Open game folder**.
  - Every change runs in a window in the middle of the screen over a dimmed background: the whole step list up front, each step ticked off live with a spinner and a progress bar, then the result with **Details** and **Copy**. The rest of the app is blocked meanwhile, and closing the app is refused until the step finishes. Uninstall first shows what it will do and asks. Icons: [Tabler Icons](https://tabler.io/icons) (MIT). Light and dark follow Windows.
  - It calls the manager's own code, so the game file fingerprints, the running-game check, the lock, the journal and the backups all apply as on the command line. Each step is its own transaction; the app stops at the first error and names the step.
- **Manager: more launch choices.** `mgs3mod launch` (and its selector) now accepts every region, language and button-prompt combination the launcher offers without extra downloads (North America: English, French, Spanish; Europe: English, French, Italian, German, Spanish; prompts keyboard, Xbox, PlayStation 4, PlayStation 5, Nintendo Switch) and passes the chosen button prompts; before, only North America, English, keyboard prompts was accepted. Japan is not offered yet. A launch profile file with the new choices is refused as a whole by older manager versions; remove `mgs3mod-launch.json` before going back to v0.4.0-alpha.1 or v0.3.0. See [direct-launch.md](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.2/docs/direct-launch.md).
- **Kit** (`mgs3-delta-controls-0.4.0-alpha.2-kit.zip`): the same manager, loader and plugin packages as alpha.1 plus `mgs3mod-gui.exe` and its notices at the root. `DELTA-CONTROLS-ALPHA.md` inside it now starts with the window app; the command-line steps are under "Advanced" ([same guide](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.2/docs/delta-controls-alpha.md)).

The window app is built with [Wails](https://wails.io) v2.14.0 (MIT) and runs in the Microsoft Edge WebView2 runtime that Windows provides; on a PC without it, the app offers to download it. Third-party notices: `THIRD-PARTY-NOTICES-GUI.txt`. The command-line zip keeps its three files and `install.ps1` is unchanged; `mgs3mod.exe` does not link Wails, and its only change since alpha.1 is the launch choices above.

Not in the window app yet (use `mgs3mod.exe`): texture mods, Crouch Walk import, and recovery after an interrupted change.

## Install

Testers: download the kit and `delta-controls-checksums.txt`, check the kit's SHA-256, extract it outside the game folder, close the game and launcher, and double-click `mgs3mod-gui.exe`. It is not code-signed: Windows SmartScreen may ask, choose **More info**, then **Run anyway**. Do not disable security software.

The manager alone installs with `-Version v0.4.0-alpha.2` through the [installer](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.2/README.md#install-without-go-or-git). Do not go back to v0.1.0 after importing a schema-4 package.

## Validation and limits

- The window app was tested on one PC (Windows 11, 100% display scaling, dark theme): automated tests of its flows against test fixtures, runs on a copy of the game folder, and on the real install Uninstall, Install, the mod switches, launch profiles (create, edit, delete) and **Launch game** with a Europe, French, Xbox prompts profile followed by a few minutes of play. Record: [v0.4.0-alpha.2-validation.md](https://github.com/nasroykh/mgs3-mod-manager/blob/main/docs/releases/v0.4.0-alpha.2-validation.md).
- **Never tested:** quick launch on a Steam copy, Steam library detection on a real Steam install, Windows 10, a PC without WebView2, display scaling above 100%, and everything listed for the plugins (a real Steam copy, Valve Steam Input, PlayStation controllers, sniper rifles and most weapons, long play). Full list: [delta-controls-untested.md](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.2/docs/delta-controls-untested.md).
- MGSHDFix must not be installed beside `fpv-move`.
- Only the compiled game fingerprints are supported. CI cannot play the game. Windows AMD64 only. Binaries are not Authenticode-signed. Verify checksums; do not disable security software.
