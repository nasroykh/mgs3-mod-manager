# MGS3 Mod Manager v0.1.0

First Windows x64 release. Install the compiled manager without Git or Go; import and manage texture mods, ASI plugins, and a standalone ASI loader.

## Install

Run in PowerShell:

```powershell
$installer = Join-Path $env:TEMP ('mgs3mod-install-' + [guid]::NewGuid().ToString('N') + '.ps1')
Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/nasroykh/mgs3-mod-manager/v0.1.0/install.ps1' -OutFile $installer
notepad $installer
# After reviewing the script:
powershell -NoProfile -ExecutionPolicy Bypass -File $installer -Version v0.1.0
```

The installer requires the release SHA-256 checksum and installs to `%LOCALAPPDATA%\Programs\mgs3mod` with a user PATH entry. Open a new terminal, then run `mgs3mod --help`. It does not install mods or modify game files. The README explains manual installation, custom paths, game initialization, and mod management.

## Assets

- `mgs3mod_0.1.0_windows_amd64.zip`: compiled manager, README, and dependency notices.
- `qcamo-1.0.4-standalone-distribution.zip`: complete starter bundle with manager, both packages, instructions, licenses, and provenance.
- `qcamo-1.0.4.mgs3mod.zip` and `asi-loader-9.7.4.mgs3mod.zip`: individual import packages.
- `install.ps1` and `checksums.txt`: installer and asset checksums.

## Scope and limitations

QCamo 1.0.4 and Ultimate ASI Loader 9.7.4 are unchanged upstream binaries, not original mods authored here. No MGSHDFix is required or installed. The user reported successful local gameplay; complete controller, cutscene, long-session, and other-mod compatibility is not certified.

Only the compiled game fingerprints are supported. Run `doctor --game-root '<game folder>'` first. Existing manual files are never adopted. Close the game and launcher before changes. Do not downgrade after schema-3 import or copy `.mgs3mod` between installations.

The release workflow runs lifecycle, conflict, dependency, recovery, installer, and real-artifact tests. Native ASIs execute code inside the game. Checksums establish identity, not security certification. The executable is not Authenticode-signed; do not disable security software to bypass warnings.
