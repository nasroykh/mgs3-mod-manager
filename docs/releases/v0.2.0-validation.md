## Upgrade and sharing limits

Use v0.2.0 or later for schema-4 history; removing Crouch Walk does not make a downgrade safe. Share the [release](https://github.com/nasroykh/mgs3-mod-manager/releases/tag/v0.2.0) and [local-import instructions](../crouch-walk.md). Each tester must obtain the original Crouch Walk download themselves. Do not distribute game originals, manager state, or the locally converted restricted mod package. Public installation proves neither every supported PC configuration nor gameplay on other game builds.
