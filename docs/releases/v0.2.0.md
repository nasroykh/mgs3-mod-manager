# MGS3 Mod Manager v0.2.0

Adds offline import and managed installation of MGS3 Crouch Walk 0.2.1 alongside QCamo, using the standalone ASI loader. No MGSHDFix is required.

## Install or upgrade

Follow the [Windows binary installation instructions](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.2.0/README.md#install-without-go-or-git). No Git or Go is required. Existing users can rerun the installer with `-Version v0.2.0`; it updates the manager, not mods or game data. Use the updated executable explicitly if multiple copies exist.

**Do not downgrade to v0.1.0 after importing a schema-4 package.** Removing the mod does not remove its transaction history. To undo Crouch Walk, close the game and run `mgs3mod disable crouch-walk --game-root <your-game-folder>` with v0.2.0 or later; QCamo and the shared loader remain installed.

## Crouch Walk local import

Download the original mod yourself from [Nexus mod 27, file 32](https://www.nexusmods.com/metalgearsolid3mc/mods/27?tab=files&file_id=32), then follow the [conversion and management instructions](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.2.0/docs/crouch-walk.md).

The new `import-crouch <archive.zip> --out <package.zip>` command verifies the exact upstream archive and creates a local manager package. It supports `--dry-run` and does not touch the game. Use normal `add` and `enable` commands afterward. Schema 4 pins all 119 payloads and original target states. The old bundled `d3d11.dll` is excluded; the managed standalone loader is required.

**No Crouch Walk payload is included in this release. Do not redistribute your generated package without appropriate permission.** The manager includes only adapter code and compatibility metadata. QCamo 1.0.4 and Ultimate ASI Loader 9.7.4 remain separate, licensed release assets.

## Validation and limits

- Local real-archive conversion, package integrity, deterministic packaging, lifecycle, drift refusal, selected mixed-file crash recovery, and explicit missing-animation recovery passed. Existing regression tests and Go vet passed.
- The user reported successful gameplay with Crouch Walk and QCamo together on the supported local installation. This is a local smoke test, not a complete gameplay matrix or universal compatibility guarantee.
- Only the compiled game fingerprints and pinned animation baseline are supported. Different builds or asset sets fail closed. The first adaptation uses an immutable managed INI; manual edits trigger drift protection.
- CI cannot perform Crouch Walk gameplay or restricted real-artifact tests without the user's game/download. It runs source/unit tests and licensed QCamo/loader artifact tests; restricted payloads are neither downloaded nor published by CI.
- Windows AMD64 only. Binaries are not Authenticode-signed. Verify release checksums; do not disable security software.
