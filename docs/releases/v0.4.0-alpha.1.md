# MGS3 Mod Manager v0.4.0-alpha.1 (prerelease)

**Alpha.** First public test build of the Delta controls plugins, plus manager support for a Steam copy of the supported game build. The installer's default ("latest") stays on v0.3.0; this build is installed only on request.

## What is new

- **Delta controls tester kit** (`mgs3-delta-controls-0.4.0-alpha.1-kit.zip`): the manager, Ultimate ASI Loader 9.7.4, `fpv-move` 0.8.4 and `qcamo-face` 1.0.4-face.4, with install steps, controls and notices. Start with `DELTA-CONTROLS-ALPHA.md` inside it ([same guide](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.1/docs/delta-controls-alpha.md)).
  - `fpv-move` 0.8.4: first-person walking, over-the-shoulder aiming with a crosshair and shots on the crosshair, strafing and moving while aiming, a Delta-style keyboard and pad layout, crouch CQC, wall aim and corner peek, D-pad windows, codec and QCamo menu, hold-ups from the shoulder aim.
  - `qcamo-face` 1.0.4-face.4: a fork of QCamo 1.0.4 (MIT) with a face paint list, a live D-pad-up menu, uniforms that keep the face paint, and taking the Mask off from the menu. It replaces `qcamo`; enable only one.
- **Steam copy of the supported build.** The executable fingerprint also accepts the SteamStub-wrapped `METAL GEAR SOLID3.exe` of the same build (SHA-256 `81596a6a670263da6ee59c959b65cbf833be985e64fa0332ad926271aa060bfe`, same PE timestamp `0x6980B92F` and section sizes as the supported executable). The other four fingerprints and the profile ID are unchanged, so existing state and packages keep working.
- **Prerelease tags.** The installer and packaging accept `vX.Y.Z-alpha.N`, `-beta.N` and `-rc.N`; latest-release lookup still skips prereleases.

## Install

Testers: download the kit and `delta-controls-checksums.txt`, check the kit's SHA-256, extract it outside the game folder and follow `DELTA-CONTROLS-ALPHA.md`.

The manager alone installs with `-Version v0.4.0-alpha.1` through the [installer](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.1/README.md#install-without-go-or-git). Do not go back to v0.1.0 after importing a schema-4 package.

## Validation and limits

- Played on one installation (North America/English, a wired Xbox Series X pad without Valve Steam Input, keyboard and mouse). The last sessions (2026-09-26 and 2026-09-27) were on the pad; since 0.7.0 nothing was played on the keyboard. Development history and logs: [delta-controls-plan.md](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.1/docs/delta-controls-plan.md).
- **Never tested:** a real Steam copy (the wrapped executable was checked with `doctor` and a full kit install and uninstall on a copied folder, not played), Valve Steam Input, PlayStation controllers, sniper rifles and most weapons, long play and boss fights. Full list: [delta-controls-untested.md](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.4.0-alpha.1/docs/delta-controls-untested.md).
- Direct `launch` was not tried on a Steam copy; start a Steam copy from Steam.
- MGSHDFix must not be installed beside `fpv-move`.
- Only the compiled game fingerprints are supported. CI cannot play the game. Windows AMD64 only. Binaries are not Authenticode-signed. Verify checksums; do not disable security software.
