Published on 2026-09-27 as a GitHub prerelease from tag `v0.4.0-alpha.2` (commit `134ebbea076bd7a0e4f13fc91ab0c2156c91948c`). The latest release stays v0.3.0 (`/releases/latest` returned `v0.3.0` after publication).

## Before the tag

- `scripts/build.ps1` passed (all Go tests, `go vet`, the CLI and the window app built with the pinned Wails CLI v2.14.0), and `scripts/package-release.ps1` produced seven assets with six checksum lines.
- The window app was reviewed by three independent reviews (first version, UI pass, launch profiles) and each finding was fixed and re-tested.
- On the local installation the user tested the window app: Uninstall and Install of the Delta controls kit, the mod switches (including turning Crouch Walk off), launch profiles (create, edit, rename, delete, default) and **Launch game** with a Europe, French, Xbox prompts profile: the game started without the Master Collection menus, showed French text and Xbox button prompts, and was played for a few minutes with fpv-move and the QCamo face paint fork loaded (`fpvmove.log` and `qcamo.log` rewritten at 23:33, no error in `qcamo.log`), then closed with Alt+F4. Manager generation 185 afterwards, `verify` passed.
