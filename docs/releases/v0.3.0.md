# MGS3 Mod Manager v0.3.0

Adds a startup-only direct-launch command for the supported North America/English installation. The manager can start MGS3 without opening the Master Collection selector. QCamo, the standalone ASI loader, and Crouch Walk local import remain as released in v0.2.0.

## Install or upgrade

Follow the [Windows binary installation instructions](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.3.0/README.md#install-without-go-or-git). No Git or Go is required. Existing users can rerun the installer with `-Version v0.3.0`; it updates the manager, not mods or game data. Use the updated executable explicitly if multiple copies exist.

**Do not downgrade to v0.1.0 after importing a schema-4 package.** Removing the mod does not remove its transaction history. v0.2.0 can still read that history, but it has no `launch` command. To undo Crouch Walk, close the game and run `mgs3mod disable crouch-walk --game-root <your-game-folder>` with v0.2.0 or later.

## Direct launch

Close the game and launcher, then start the tested preset:

```powershell
mgs3mod launch --profile na-startup --game-root <your-game-folder>
```

`mgs3mod launch --select --game-root <your-game-folder>` opens the selector. The built-in `na-startup` preset is North America, English, keyboard prompts, and destination `startup`. Its native arguments are:

```text
-region us -lan en -selfregion EU -launcherpath launcher.exe -ctrltype KBD
```

`-selfregion EU` matches the tested installation's launcher region. Other regions, languages, controller-prompt modes, and game builds are rejected. Literal Main Menu arrival and save autoload are not included. Saved preferences live in `mgs3mod-launch.json` in the game folder and stay outside mod transactions. The preset is not written until an explicit selector save or default action. See [direct launch](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.3.0/docs/direct-launch.md).

## Crouch Walk local import

Download the original mod yourself from [Nexus mod 27, file 32](https://www.nexusmods.com/metalgearsolid3mc/mods/27?tab=files&file_id=32), then follow the [conversion and management instructions](https://github.com/nasroykh/mgs3-mod-manager/blob/v0.3.0/docs/crouch-walk.md).

**No Crouch Walk payload is included in this release. Do not redistribute your generated package without appropriate permission.** The manager includes only adapter code and compatibility metadata. QCamo 1.0.4 and Ultimate ASI Loader 9.7.4 remain separate, licensed release assets.

## Validation and limits

- On 2026-09-21 the installed manager launched the supported local game with `launch --profile na-startup`. The receipt reported the expected executable and argument array, and no launcher process was present. About twelve seconds later the visible screen was the in-game DATA LOAD menu, not the Master Collection selector. Closing the main window exited the process. The two game-save files kept their pre-launch hashes. The launcher `usersv` file changed hash at the same size, which matches an earlier direct-launch trial and is not a game-save rewrite. QCamo logged readiness during the process. The existing QCamo crash dump timestamp did not change. `verify --json` stayed compatible at generation 15.
- That launch did not play through Crouch Walk and did not record the frame before DATA LOAD. Earlier the same day, the same native argument route was user-tested through a manual save load with QCamo and Crouch Walk working. Omitting `-launcherpath launcher.exe` remains unsupported because that earlier trial crashed on shutdown.
- Only the compiled game fingerprints are supported. CI cannot play the game. Windows AMD64 only. Binaries are not Authenticode-signed. Verify release checksums; do not disable security software.
